🔧 Features
	Java GUI for user interaction and device control

	Serial communication with Arduino for real-time automation (e.g., lights, fans, sensors)

	User authentication using a SQL database

	Weather data integration using Fastcast API

	Maven for dependency management and project structure

📡 Technologies Used
	Java (Swing/JavaFX for UI)

	Arduino (via serial port communication)

	MySQL (or other SQL DB) for login system

	Fastcast (weather API)

	Maven (build tool)

📌 Use Cases
	Control home appliances like lights, fans, or sensors remotely

	Secure login with credential validation

	View current weather conditions in the app interface
